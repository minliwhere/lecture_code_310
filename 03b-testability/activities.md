# 03b Lecture Activities

## Write tests for printStatus

There’s a new printStatus function that tells front-desk staff whether an offering is still taking registrations. But, there are no tests for it!

1. Analyze: what behaviour do we need to verify?
2. Design: try to write tests that verify the behaviour.
3. Reflect: what aspects of printStatus made it difficult to test?
4. Refactor: update printStatus to improve its testability.
